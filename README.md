Paris Trip Planner Chatbot

Overview

This project uses the OpenAI API and generative AI to create a chatbot that can help users plan a trip to Paris.
The chatbot can provide personalised suggestions for attractions, restaurants and activities and can help organise these recommendations into a potential itinerary.

Technologies Used
- Python
- OpenAI API
- Generative AI / Large Language Models (LLMs)
- Jupyter Notebook
- Pandas
- Matplotlib

How it works

The project sends user prompts to an OpenAI model through the API. The model interprets the user's requirements and generates relevant responses based on the information provided.

Users can ask the chatbot about things such as:
- Places to visit
- Restaurants
- Activities
- Trip ideas
- Personalised itineraries

The project demonstrates how an LLM can be integrated into a Python application to create an interactive AI-powered travel planning experience.

How to Run / Test
1. Clone or download this repository.
2. Open the Jupyter Notebook (.ipynb file).
3. Set up an OpenAI API key as required by the notebook.
4. Install the required Python libraries.
5. Run the notebook cells.
6. Enter a travel-related prompt or use one of the example prompts.
7. Review the chatbot's generated recommendations.
