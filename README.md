Paris Trip Planner Chatbot

Overview

This project is a user-friendly, AI-driven travel guide that significantly enhances the exploration of Paris. Users will be able to pre-define their questions and receive well-informed answers from the AI, providing a seamless and intuitive travel planning process.
The chatbot can assist with areas such as attractions, activities, restaurants, sightseeing and creating ideas for an itinerary.

Features
- Interactive AI chatbot for travel planning
- Recommendations for attractions and activities in Paris
- Help creating a personalised itinerary
- Uses the OpenAI API to generate responses

Technologies Used
- Python
- OpenAI API
- Jupyter Notebook

How it works

The user interacts with the chatbot by entering questions or requests about their trip to Paris. These prompts are sent to the OpenAI API, which processes the request and generates a relevant response.
The project demonstrates how an AI-powered application can use a large language model to provide personalised, conversational assistance for a real-world use case.
