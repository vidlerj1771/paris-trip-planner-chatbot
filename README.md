Paris Trip Planner Chatbot

Overview

This project uses the OpenAI API and generative AI to create an interactive chatbot that helps users plan a trip to Paris.

The chatbot provides personalised suggestions for attractions, restaurants and activities and can use the user's requirements to help create a potential itinerary.

What I Built

I developed a Python-based travel planning chatbot that integrates the OpenAI API to generate personalised recommendations based on user prompts.

The chatbot allows users to ask about:

- Places to visit
- Restaurants
- Activities
- Trip ideas
- Personalised itineraries

The project demonstrates how an LLM can be integrated into a Python application to create an interactive AI-powered experience.

How It Works
1. The user provides a travel-related prompt or request.
2. The prompt is sent to an OpenAI model through the API.
3. The model interprets the user's requirements.
4. The AI generates relevant recommendations based on the information provided.
5. The response is presented to the user as personalised travel guidance.

How to Run / Test
1. Clone or download this repository.
2. Open the Jupyter Notebook (.ipynb file).
3. Install the required Python libraries.
4. Set up an OpenAI API key as required by the notebook.
5. Run the notebook cells from beginning to end.
6. Enter a travel-related prompt or use one of the example prompts.
7. Review the chatbot's generated recommendations.

The notebook contains the code and steps required to reproduce the project.

Project Outcome

This project demonstrates how the OpenAI API and generative AI can be integrated with Python to build an interactive chatbot capable of understanding user requirements and generating personalised responses.
